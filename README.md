E-commerce Product Sorting Using Divide and Conquer

1. Introduction

This project is based on sorting products in an e-commerce application using the Divide and Conquer strategy.

In online shopping applications, many products are available at different prices. Sorting products by price helps customers find products easily.

This project uses the Merge Sort algorithm to arrange products from low price to high price.

2. Objectives

- To understand the Divide and Conquer strategy.
- To implement the Merge Sort algorithm using Python.
- To sort products according to their prices.
- To display products in sorted order.

3. Technologies Used

- Programming Language: Python
- Algorithm: Merge Sort
- Strategy: Divide and Conquer

4. Working of the Project

The project contains a list of products with their names and prices.

The Merge Sort algorithm works in three steps:

1. Divide: The product list is divided into two smaller parts.
2. Conquer: Both parts are sorted recursively.
3. Merge: The sorted parts are combined into one sorted list.

Finally, the products are displayed from the lowest price to the highest price.

7. Algorithm

1. Start the program.
2. Create a list of products with their prices.
3. Divide the list into two halves.
4. Sort both halves using Merge Sort.
5. Merge the sorted halves according to price.
6. Display the sorted product list.
7. Stop the program.

8. Time Complexity

The time complexity of Merge Sort is O(n log n), where "n" is the number of products.

9. Advantages

- Easy to understand and implement.
- Efficient for sorting large lists.
- Organizes products according to price.
- Demonstrates the Divide and Conquer strategy.
